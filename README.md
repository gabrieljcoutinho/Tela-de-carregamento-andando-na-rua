# Scenic Night View - CSS Art

Este projeto é uma obra de arte digital construída exclusivamente com **HTML5** e **CSS3**, simulando uma rua noturna com postes de iluminação, pavimentação em perspectiva e um céu estrelado.

## 🧱 Estrutura do Código

O projeto utiliza uma hierarquia profunda de elementos `div` para construir formas complexas sem o uso de imagens ou JavaScript.

### Componentes Principais:

* **Luminárias (`.lamp`):** Estruturas detalhadas divididas em `head` (topo, fonte de luz e vidro), `rod` (poste central) e `bottom` (base).
* **Pavimentação (`.masonry-perspective`):** Um sistema de grid que utiliza contêineres e itens para criar um efeito de calçamento. A classe sugere a aplicação de transformações 3D para gerar profundidade.
* **Céu e Estrelas (`.sky`):** Um contêiner que abriga múltiplas estrelas individuais, preparadas para efeitos de animação e brilho.
* **Chão (`.ground`):** Define a base da cena e o horizonte.

## 🛠 Tecnologias

* **HTML5:** Estruturação dos componentes.
* **CSS3:** Estilização, filtros de luz, sombras e perspectiva 3D (via `style.css`).

## 🚀 Como usar

1.  Crie um arquivo chamado `index.html` e cole o código fornecido.
2.  Crie um arquivo chamado `style.css` na mesma pasta.
3.  Abra o `index.html` em qualquer navegador moderno.

---
Este código é ideal para estudos de **CSS avançado**, manipulação de **Pseudo-elementos** (`::before` / `::after`) e **Transformações 3D**.
